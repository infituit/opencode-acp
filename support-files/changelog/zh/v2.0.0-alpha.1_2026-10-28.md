## [Version: v2.0.0-alpha.1] - 2026-10-28

> 本版本为 Alpha 预发布，仅支持 OpenCode V2。升级前请备份现有状态，并移除旧的 ACP 插件配置。

**发布范围**

- ACP 2.0 的首个 Alpha，包含当前 `master` 上的 OpenCode V2 插件实现。
- 仅通过 GitHub 分发，不发布到 npm；`opencode-acp@stable` 和 `opencode-acp@latest` 不会安装本版本。

**主要变更**

- 将插件入口和运行时集成迁移到 OpenCode V2 插件 API。
- 接入 V2 宿主的工具、`/acp` 命令、会话 hooks、事件和原生插件存储。
- 转换 V2 消息，接入 ACP 的压缩与恢复流程。
- 保留模型驱动的三级压缩、解压、上下文状态查看和压缩内容搜索。

**兼容性与升级前置条件**

- 要求 **OpenCode >=2.1.4 且 <3**，不支持 OpenCode 1.x。
- 安装需要 Git 和 Node.js/npm，Git 安装过程会构建插件。
- 安装前移除旧的 npm 或本地 ACP 插件项，避免重复加载。
- 默认使用 OpenCode 原生插件存储。请备份旧状态并新建会话；复制 V1 JSON 状态文件不会迁移会话或压缩块。

**安装**

```bash
opencode plugin add github:infituit/opencode-acp#v2.0.0-alpha.1
```

安装后执行 `/reload`，开启新会话并使用 `/acp` 确认插件可用。
