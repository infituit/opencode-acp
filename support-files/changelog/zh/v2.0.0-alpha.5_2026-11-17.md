## [Version: v2.0.0-alpha.5] - 2026-11-17

Full Changelog: [v2.0.0-alpha.4...v2.0.0-alpha.5](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.4...v2.0.0-alpha.5)

**发布范围**

- ACP 2.0 Alpha 维护更新，移除冗余的工具历史处理、调整 V2 集成层结构并更新 Zod 依赖。

**功能优化**

- 移除未被使用的工具参数缓存及其历史同步步骤，避免每次消息转换时执行这部分冗余工作；保留工具调用顺序记录与 token 统计。
- 将 hook handlers 迁入 `src/v2/`，集中维护 OpenCode V2 宿主集成逻辑。

**缺陷修复**

- 将 Zod 最低允许版本提高到 `4.6.6`，排除安全公告 [GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5) 涉及的受影响版本。

**兼容性与升级前置条件**

- 要求 **OpenCode >=2.1.4 且 <3**。
- 不修改公开 API、配置、持久化状态格式、message refs 或 compression block IDs。

**已知问题**

- 长历史会话的请求前等待问题仍在排查中，本版不代表整体性能问题已经解决，见 [#34](https://github.com/infituit/opencode-acp/issues/34) 和 [#51](https://github.com/infituit/opencode-acp/issues/51)。
