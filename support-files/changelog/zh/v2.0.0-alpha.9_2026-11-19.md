## [Version: v2.0.0-alpha.9] - 2026-11-19

Full Changelog: [v2.0.0-alpha.8...v2.0.0-alpha.9](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.8...v2.0.0-alpha.9)

**发布范围**

- ACP 2.0 Alpha 维护更新，改善模型上下文窗口未知时的目录恢复、诊断和 fallback 提示。

**缺陷修复**

- 修复模型目录补载仅尝试一次的问题：目录未命中时，后续请求可重新加载；并发请求共享进行中的加载，每次完成后冷却 30 秒，避免未知模型每轮都触发目录请求。
- 补充目录加载诊断，区分 API 不可用、响应结构错误、请求失败、空目录和无有效上下文窗口；记录条目数量，不记录原始响应或异常正文。
- 修正未知窗口告警，准确区分使用 `compress.contextLimitFallback` 与禁用 fallback，不再错误声称默认 fallback 下所有相关检查均已禁用。
- 补充 fallback 配置与预算风险说明，修正缺陷报告模板中的 OpenCode V2 支持范围。

**兼容性与升级前置条件**

- 要求 **OpenCode >=2.1.4 且 <3**。
- 不增加配置项或依赖，不改变持久化状态格式；从 alpha.8 升级无需数据迁移。
- `compress.contextLimitFallback` 默认仍为 `128000`，设为 `0` 可禁用。恢复真实模型窗口后，相关阈值会改按该窗口计算。

**已知问题**

- 本版不包含摘要引用保真门禁的调整，不保证解决 [#60](https://github.com/infituit/opencode-acp/issues/60) 中所有压缩后重复取证现象。
- fallback 不会扩大模型真实容量；自定义模型应优先正确配置 OpenCode 的 `limit.context`。
