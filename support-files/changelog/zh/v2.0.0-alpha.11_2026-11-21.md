## [Version: v2.0.0-alpha.11] - 2026-11-21

Full Changelog: [v2.0.0-alpha.10...v2.0.0-alpha.11](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.10...v2.0.0-alpha.11)

**发布范围**

- ACP 2.0 Alpha 文件保护维护更新，修复配置 `protectedFilePatterns` 后对 V2 文件工具参数识别不完整的问题。

**缺陷修复**

- 识别文件工具的 `path` 参数，保留已有 `filePath` 和 `multiedit` 路径提取行为，使匹配文件参与现有压缩过滤、范围保护提示和工具输出保留。
- 识别 `patch.patchText`，保留 `apply_patch` 支持；新增、修改、删除及重命名目标路径均参与保护判断，重命名源路径同样保留。
- 避免将补丁新增正文中的类似操作头文本误判为文件路径。

**兼容性与升级前置条件**

- 要求 **OpenCode >=2.1.4 且 <3**。
- 不新增配置项或依赖，不改变 glob 匹配规则、持久化格式、message refs 或 compression block IDs；从 alpha.10 升级无需数据迁移。
- 文件保护仍需配置匹配的 `protectedFilePatterns`，不会默认启用，也不会自动恢复已经压缩的消息。此前漏判的匹配消息升级后可能不再进入可压缩范围。

**已知问题**

- 本版仅修复公共路径提取，不改变 OpenCode 原生 compaction 或其他压缩器的行为。
- 本版不包含 [#51](https://github.com/infituit/opencode-acp/issues/51) 中的图片/base64、解压预算修复，也不消除全部长历史扫描与等待。
