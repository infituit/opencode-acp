## [Version: v2.0.0-alpha.3] - 2026-11-02

Full Changelog: [v2.0.0-alpha.2...v2.0.0-alpha.3](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.2...v2.0.0-alpha.3)

**发布范围**

- ACP 2.0 Alpha 更新，新增可长期保留的上下文处理诊断机制，通过 GitHub Release 和 npm `alpha` 渠道分发。

**新增功能**

- 在现有 daily log 中记录结构化请求摘要，包含会话与请求标识、处理结果、总耗时、分阶段耗时及消息和压缩块数量，便于关联慢请求和失败位置。
- 提供仓库内只读日志汇总工具，支持按会话筛选、重复记录去重，以及 P50、P95、最大耗时和阶段热点统计。该工具不包含在 npm 包中。

**缺陷修复**

- 日志时间戳改为在调用时捕获，避免后续同步处理延迟时间戳，影响排查判断。

**兼容性与升级前置条件**

- 要求 **OpenCode >=2.1.4 且 <3**。
- 无新增配置字段，不改变压缩行为或持久化状态格式；继续使用现有 `logLevel` 控制记录范围。
- `info` 记录请求完成摘要；`debug` 额外记录开始与阶段轨迹。现有 debug 内容快照可能包含敏感信息，共享前请检查。

**已知问题**

- 本版本提供排查能力，尚未修复长历史会话的请求前等待问题，见 [#34](https://github.com/infituit/opencode-acp/issues/34)。
- 阶段耗时是经过时间，不代表独占 CPU 耗时；父子处理链存在重叠，不能相加。进程崩溃、卡死或日志写入失败时可能缺少完成记录。
