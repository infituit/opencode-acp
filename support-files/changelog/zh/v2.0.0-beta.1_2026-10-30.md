## [Version: v2.0.0-beta.1] - 2026-10-30

Full Changelog: [v2.0.0-alpha.1...v2.0.0-beta.1](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.1...v2.0.0-beta.1)

**发布范围**

- ACP 2.0 首个 Beta，仅支持 OpenCode V2。
- 通过 GitHub Release 和 npm 包 `@infituit/opencode-acp` 分发；本版本使用 npm `beta` 渠道，不更新 `latest`。

**功能优化**

- 发布流程复用 GitHub Release 的预构建安装包发布到 npm，npm 安装无需从 Git 源码构建。
- 精简使用文档，明确配置加载顺序、工具保护、质量门控和插件维护范围。

**缺陷修复**

- 将自动更新的目标包名改为 `@infituit/opencode-acp`，与本项目实际发布的 npm 包保持一致。

**兼容性与升级前置条件**

- 要求 **OpenCode >=2.1.4 且 <3**，不支持 OpenCode 1.x。
- 安装或切换来源前移除已有的 ACP npm、Git 或本地插件项，避免重复加载；无 scope 的 `opencode-acp` 不是本项目发布的包。
- 禁用 OpenCode 内置自动压缩，避免与 ACP 的上下文管理冲突。
- 本次未变更 ACP 配置字段或持久化格式。首次从 V1 升级时，请备份旧状态并新建会话；复制 V1 JSON 状态文件不会迁移会话或压缩块。

**已知问题**

- 长历史会话的 V2 上下文处理仍可能在模型请求发送前增加明显等待；已有约 8–9 秒及 36.7 秒的报告，尚未修复，见 [#34](https://github.com/infituit/opencode-acp/issues/34)。

**安装**

```bash
opencode plugin add @infituit/opencode-acp@2.0.0-beta.1
```

也可使用 `@beta` 跟随 Beta 渠道。安装后执行 `/reload`，开启新会话并使用 `/acp` 确认插件可用。
