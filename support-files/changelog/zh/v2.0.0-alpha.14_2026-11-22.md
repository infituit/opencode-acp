## [Version: v2.0.0-alpha.14] - 2026-11-22

Full Changelog: [v2.0.0-alpha.13...v2.0.0-alpha.14](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.13...v2.0.0-alpha.14)

**发布范围**

- ACP 2.0 Alpha 上下文计数维护更新，修复可见 reasoning 在共享估算中被遗漏的问题。

**缺陷修复**

- 将当前请求中保留的 reasoning 纳入共享上下文估算，避免缺少 provider usage 时低估占用；请求时已移除的 reasoning 不再计入。
- 解压预算投影复用共享计数，移除独立累加，避免 reasoning 被重复计算；保持原有文本与工具内容的合并计数方式。

**兼容性与升级前置条件**

- 要求 **OpenCode >=2.1.4 且 <3**。
- 不新增配置项或依赖，不改变持久化格式、message refs 或 compression block IDs；从 alpha.13 升级无需数据迁移。
- 含可见 reasoning 的请求可能更早触发已有上下文提示或预算保护；不改变 reasoning 移除规则或历史 provider usage 的处理方式。

**已知问题**

- 上下文估算仍不包含原生媒体的实际成本，也不等同于 provider 的精确请求预算。本版不代表 [#51](https://github.com/infituit/opencode-acp/issues/51) 的全部问题均已解决。
