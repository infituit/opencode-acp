## [Version: v2.0.0-alpha.7] - 2026-11-17

Full Changelog: [v2.0.0-alpha.6...v2.0.0-alpha.7](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.6...v2.0.0-alpha.7)

**发布范围**

- ACP 2.0 Alpha 维护更新，修复 V2 模型上下文上限的读取与使用。

**缺陷修复**

- 修复模型目录响应解析错误，避免目录中已有上下文上限的模型仍使用 fallback。
- system prompt 阶段按当前 provider/model 读取同一模型目录中的上限，不再固定传入零值。
- 依赖上下文上限的百分比阈值按当前模型目录值计算；未知模型继续沿用既有 fallback 行为。

**兼容性与升级前置条件**

- 要求 **OpenCode >=2.1.4 且 <3**。
- 不改变配置、持久化状态格式、message refs 或 compression block IDs；从 alpha.6 升级无需进行这些数据的迁移。

**已知问题**

- 本修复不保证本地 token 估算等同于 provider 的实际请求预算，也不代表 [#51](https://github.com/infituit/opencode-acp/issues/51) 中的性能及图片压缩问题已全部解决。
