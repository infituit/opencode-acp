## [Version: v2.0.0-alpha.8] - 2026-11-19

Full Changelog: [v2.0.0-alpha.7...v2.0.0-alpha.8](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.7...v2.0.0-alpha.8)

**发布范围**

- ACP 2.0 Alpha 维护更新，修复后台 agent handoff 在 V2 模型请求中被静默丢弃的问题。

**缺陷修复**

- 保留当前请求已交付的后台 agent 结果及其消息标识和 metadata，支持仅包含 handoff、没有人工 prompt 的请求。
- 区分 handoff 与人工 prompt，避免错误应用用户消息保护；压缩后不再重新带回 handoff 原文，持久化重启后仍可解压恢复。
- 防止运行中晚到、模型尚未看到的 handoff 被提前纳入压缩。
- 保留已有 message refs，按实际消息顺序规划压缩范围；历史引用无法可靠恢复时保留原始历史，避免错误裁剪。

**兼容性与升级前置条件**

- 要求 **OpenCode >=2.1.4 且 <3**。
- 不增加配置项或依赖，不改变持久化状态格式或 compression block IDs；从 alpha.7 升级无需数据迁移。
- 新压缩结果包含内部引用语义标记；缺少可靠历史引用时，部分历史会保持未压缩状态。

**已知问题**

- 本版不包含 [#51](https://github.com/infituit/opencode-acp/issues/51) 中的图片/base64、解压预算或其他性能问题修复，也不代表所有后台 agent 唤醒问题均已解决。
