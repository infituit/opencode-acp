## [Version: v2.0.0-alpha.4] - 2026-11-09

Full Changelog: [v2.0.0-alpha.3...v2.0.0-alpha.4](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.3...v2.0.0-alpha.4)

**发布范围**

- ACP 2.0 Alpha 维护更新，整理 hooks 代码结构并明确后续 V2 集成边界，通过 GitHub Release 和 npm `alpha` 渠道分发。

**功能优化**

- 将 hooks 按 system、messages、command、text 和 event 职责拆分，保留统一入口和现有处理逻辑，便于独立维护各类 handler。
- 补充 hook 回归测试，并记录 V2 宿主集成层与业务能力模块的职责边界。hooks 迁入 `src/v2/` 留待后续轮次完成。

**兼容性与升级前置条件**

- 要求 **OpenCode >=2.1.4 且 <3**。
- 本次更新不修改公开 API、依赖、配置或持久化状态格式，不改变 message refs 和 compression block IDs。

**已知问题**

- 本次结构调整不修复长历史会话的请求前等待问题，见 [#34](https://github.com/infituit/opencode-acp/issues/34)。
