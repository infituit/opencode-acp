# v2.0.0 — OpenCode V2

Version: v2.0.0

ACP 2.0 是首个使用 OpenCode V2 插件 API 的版本。

## 兼容性与升级

- 要求 **OpenCode >=2.1.4 且 <3**，不支持 OpenCode 1.x。
- **仅通过 GitHub 分发**，本版本未发布到 npm。安装 `opencode-acp@stable` 或 `opencode-acp@latest` 不会安装 v2.0.0。
- 安装前移除已有的 npm 或本地 ACP 插件项，避免同时加载多个副本。
- ACP 默认改用 OpenCode 原生插件存储。请备份旧状态并新建会话；复制 V1 JSON 状态文件不会迁移会话或压缩块。

## 主要变更

- 将插件入口及运行时集成迁移到 OpenCode V2 API（[#18](https://github.com/infituit/opencode-acp/pull/18)）。
- 通过 V2 宿主集成工具、`/acp` 命令、会话 hooks、事件和持久化。
- 转换 V2 消息以接入 ACP 现有的压缩与恢复流程。
- 保留模型驱动的三级压缩、解压、上下文状态查看与压缩内容搜索。

## 从 GitHub 安装

准备好 Git 和 Node.js/npm 后，安装固定的 release tag：

```bash
opencode plugin add github:infituit/opencode-acp#v2.0.0
```

也可以在 `opencode.json(c)` 中添加：

```json
{
    "$schema": "https://opencode.ai/config.json",
    "plugins": ["github:infituit/opencode-acp#v2.0.0"]
}
```

更新配置后执行 `/reload`。
