## [Version: v2.0.0-alpha.5] - 2026-11-17

Full Changelog: [v2.0.0-alpha.4...v2.0.0-alpha.5](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.4...v2.0.0-alpha.5)

**Release scope**

- An ACP 2.0 Alpha maintenance update removing redundant tool-history processing, organizing the V2 integration layer, and updating Zod.

**Improvements**

- Remove the unused tool parameter cache and its history synchronization step, avoiding this redundant work during each message transform while retaining tool-call ordering and token accounting.
- Move hook handlers into `src/v2/` to keep OpenCode V2 host integration logic together.

**Fixes**

- Raise the minimum allowed Zod version to `4.6.6`, excluding versions affected by [GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5).

**Compatibility and upgrade prerequisites**

- Requires **OpenCode >=2.1.4 and <3**.
- No changes to public APIs, configuration, persisted state formats, message refs, or compression block IDs.

**Known issues**

- Pre-request delays in long-history sessions remain under investigation. This release does not resolve the overall performance issues tracked in [#34](https://github.com/infituit/opencode-acp/issues/34) and [#51](https://github.com/infituit/opencode-acp/issues/51).
