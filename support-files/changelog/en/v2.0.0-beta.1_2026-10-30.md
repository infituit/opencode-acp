## [Version: v2.0.0-beta.1] - 2026-10-30

Full Changelog: [v2.0.0-alpha.1...v2.0.0-beta.1](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.1...v2.0.0-beta.1)

**Release scope**

- The first ACP 2.0 Beta, supporting OpenCode V2 only.
- Distributed through GitHub Release and the npm package `@infituit/opencode-acp`. This version uses the npm `beta` channel without updating `latest`.

**Improvements**

- Publish the prebuilt GitHub Release package to npm without rebuilding it. Installing from npm does not require a Git source build.
- Simplify usage documentation and clarify configuration loading, tool protection, quality gates, and the scope of plugin maintenance.

**Fixes**

- Change the automatic update target to `@infituit/opencode-acp`, matching the npm package published by this project.

**Compatibility and upgrade prerequisites**

- Requires **OpenCode >=2.1.4 and <3**; OpenCode 1.x is not supported.
- Remove existing ACP npm, Git, or local plugin entries before installing or switching sources to avoid duplicate loading. The unscoped `opencode-acp` package is not published by this project.
- Disable OpenCode's built-in automatic compaction to avoid conflicts with ACP context management.
- This release does not change ACP configuration fields or the persisted state format. When upgrading from V1, back up existing state and start a new session; copying V1 JSON state files does not migrate sessions or compression blocks.

**Known issues**

- V2 context processing in long-history sessions can still introduce noticeable delays before a model request is sent. Delays of approximately 8–9 seconds and 36.7 seconds have been reported and remain unresolved; see [#34](https://github.com/infituit/opencode-acp/issues/34).

**Installation**

```bash
opencode plugin add @infituit/opencode-acp@2.0.0-beta.1
```

Alternatively, use `@beta` to follow the Beta channel. Run `/reload` after installation, start a new session, and use `/acp` to confirm the plugin is available.
