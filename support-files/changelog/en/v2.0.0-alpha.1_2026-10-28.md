## [Version: v2.0.0-alpha.1] - 2026-10-28

> This is an Alpha prerelease for OpenCode V2 only. Back up existing state and remove previous ACP plugin entries before upgrading.

**Release scope**

- The first ACP 2.0 Alpha, containing the OpenCode V2 plugin implementation on the current `master`.
- Distributed through GitHub only, not npm. Neither `opencode-acp@stable` nor `opencode-acp@latest` installs this version.

**Changes**

- Migrate the plugin entrypoint and runtime integration to the OpenCode V2 plugin API.
- Integrate tools, the `/acp` command, session hooks, events, and native plugin storage with the V2 host.
- Convert V2 messages for ACP’s compression and recovery pipeline.
- Retain model-driven three-tier compression, decompression, context status, and compressed-context search.

**Compatibility and upgrade prerequisites**

- Requires **OpenCode >=2.1.4 and <3**; OpenCode 1.x is not supported.
- Installation requires Git and Node.js/npm. Installing from Git builds the plugin.
- Remove previous npm or local ACP plugin entries before installing to avoid loading multiple copies.
- Native OpenCode plugin storage is used by default. Back up existing state and start a new session; copying V1 JSON state files does not migrate sessions or compression blocks.

**Installation**

```bash
opencode plugin add github:infituit/opencode-acp#v2.0.0-alpha.1
```

Run `/reload` after installation, start a new session, and use `/acp` to confirm the plugin is available.
