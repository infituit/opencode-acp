## [Version: v2.0.0-alpha.4] - 2026-11-09

Full Changelog: [v2.0.0-alpha.3...v2.0.0-alpha.4](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.3...v2.0.0-alpha.4)

**Release scope**

- An ACP 2.0 Alpha maintenance update organizing hook implementations and defining the target V2 integration boundary, distributed through GitHub Release and the npm `alpha` channel.

**Improvements**

- Separate hook implementations by system, messages, command, text, and event responsibilities while retaining a single entry point and existing processing logic.
- Add hook regression tests and document the boundary between V2 host integration and ACP capabilities. Relocating hooks into `src/v2/` remains separate follow-up work.

**Compatibility and upgrade prerequisites**

- Requires **OpenCode >=2.1.4 and <3**.
- This update does not change public APIs, dependencies, configuration, persisted state formats, message refs, or compression block IDs.

**Known issues**

- This structural update does not fix pre-request delays in long-history sessions. See [#34](https://github.com/infituit/opencode-acp/issues/34).
