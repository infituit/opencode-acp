## [Version: v2.0.0-alpha.8] - 2026-11-19

Full Changelog: [v2.0.0-alpha.7...v2.0.0-alpha.8](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.7...v2.0.0-alpha.8)

**Release scope**

- An ACP 2.0 Alpha maintenance update fixing background-agent handoffs silently dropped from V2 model requests.

**Fixes**

- Preserve background-agent results already delivered to the current request, including message identity and metadata. Support handoff-only requests without a human prompt.
- Distinguish handoffs from human prompts to avoid incorrect user-message protection. Compressed handoff payloads no longer reappear, and decompression remains available after a persisted restart.
- Prevent late-arriving handoffs that the model has not seen from being compressed prematurely.
- Preserve existing message refs and plan compression ranges in transcript order. Retain raw history when historical references cannot be recovered reliably, avoiding incorrect pruning.

**Compatibility and upgrade prerequisites**

- Requires **OpenCode >=2.1.4 and <3**.
- No new configuration options or dependencies, and no changes to persisted state formats or compression block IDs. Upgrading from alpha.7 requires no data migration.
- New compression results include an internal reference-semantics marker. Some history remains uncompressed when reliable historical references are unavailable.

**Known issues**

- This release does not include fixes for image/base64 handling, decompression budgets, or other performance issues tracked in [#51](https://github.com/infituit/opencode-acp/issues/51), and does not resolve every background-agent wake-up issue.
