## [Version: v2.0.0-alpha.16] - 2026-11-24

Full Changelog: [v2.0.0-alpha.15...v2.0.0-alpha.16](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.15...v2.0.0-alpha.16)

**Release scope**

- An ACP 2.0 Alpha update for fork compression-state recovery, including [#80](https://github.com/infituit/opencode-acp/pull/80) and [#81](https://github.com/infituit/opencode-acp/pull/81).

**New features**

- `/acp recover-fork`: preview recovery for an existing empty fork without writing ACP state or a backup.
- `/acp recover-fork --apply`: create a private backup before restoring verifiable compression state from the source.
- `/acp recover-fork --rollback <backup-id>`: undo that recovery, refusing to overwrite subsequent state changes.

**Fixes**

- Recognize `fork.sessionID` during first-time fork initialization, independently of the subagent `parentID` relationship.
- Respect the configured storage location and fork boundary when reading the source. Translate compression records and verifiable frozen tool outputs to fork IDs instead of incorrectly inheriting source call IDs.

**Compatibility and upgrade prerequisites**

- Requires **OpenCode >=2.1.4 and <3**.
- No new dependencies or configuration options, and no changes to existing session persistence formats, message refs, or compression block IDs. Upgrading from alpha.15 requires no data migration.
- Existing empty forks are not repaired automatically; preview recovery before explicitly applying it.
- Recovery and rollback require an idle session accessed by a single OpenCode instance. Backups contain session state and summaries and must be kept private.

**Known issues**

- Recovery is unavailable for sessions with inactive/decompressed records, historical counters, or ambiguous decompression history. Unavailable sources, missing boundaries, uncertain mappings, and incomplete nested blocks cause recovery to be refused.
- This release does not guarantee resolution of all long-history processing and service-recovery problems tracked in [#34](https://github.com/infituit/opencode-acp/issues/34).
