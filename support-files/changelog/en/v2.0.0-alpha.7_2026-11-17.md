## [Version: v2.0.0-alpha.7] - 2026-11-17

Full Changelog: [v2.0.0-alpha.6...v2.0.0-alpha.7](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.6...v2.0.0-alpha.7)

**Release scope**

- An ACP 2.0 Alpha maintenance update fixing how V2 model context limits are loaded and used.

**Fixes**

- Fix model catalog response parsing so models with a catalog-provided context limit no longer incorrectly use the fallback.
- Resolve the context limit for the current provider/model from the same catalog during system prompt processing instead of always passing zero.
- Percentage-based thresholds use the current model's catalog limit. Unknown models retain the existing fallback behavior.

**Compatibility and upgrade prerequisites**

- Requires **OpenCode >=2.1.4 and <3**.
- No changes to configuration, persisted state formats, message refs, or compression block IDs. Upgrading from alpha.6 requires no migration of these data.

**Known issues**

- This fix does not guarantee that local token estimates match the provider's actual request budget, nor does it resolve all performance and image-compression issues tracked in [#51](https://github.com/infituit/opencode-acp/issues/51).
