## [Version: v2.0.0-alpha.3] - 2026-11-02

Full Changelog: [v2.0.0-alpha.2...v2.0.0-alpha.3](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.2...v2.0.0-alpha.3)

**Release scope**

- An ACP 2.0 Alpha update introducing persistent context-processing diagnostics, distributed through GitHub Release and the npm `alpha` channel.

**New features**

- Record structured request summaries in the existing daily log, including session and trace IDs, outcomes, total and per-stage durations, and message and compression-block counts.
- Add a read-only repository tool for session filtering, deduplication, P50/P95/maximum durations, and stage hotspot summaries. The tool is not included in the npm package.

**Fixes**

- Capture log timestamps at invocation time so subsequent synchronous work does not delay timestamps and mislead investigations.

**Compatibility and upgrade prerequisites**

- Requires **OpenCode >=2.1.4 and <3**.
- No new configuration fields or changes to compression behavior or persisted state formats. Diagnostics use the existing `logLevel`.
- `info` records completion summaries; `debug` adds request-start and stage breadcrumbs. Existing debug content snapshots may contain sensitive information; review logs before sharing.

**Known issues**

- This release adds diagnostic capabilities; it does not fix pre-request delays in long-history sessions. See [#34](https://github.com/infituit/opencode-acp/issues/34).
- Stage durations measure elapsed time, not exclusive CPU usage. Parent and child lanes overlap and must not be added together. Crashes, hangs, or log-write failures may leave no completion record.
