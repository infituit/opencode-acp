# v2.0.0 — OpenCode V2

Version: v2.0.0

ACP 2.0 is the first release for the OpenCode V2 plugin API.

## Compatibility and upgrade

- Requires **OpenCode >=2.1.4 and <3**; OpenCode 1.x is not supported.
- Distributed through **GitHub only**. This release is not published to npm. Installing `opencode-acp@stable` or `opencode-acp@latest` does not install v2.0.0.
- Remove previous npm or local ACP plugin entries before installing to avoid loading multiple copies.
- ACP now uses OpenCode's native plugin storage by default. Back up your existing state and start a new session; copying V1 JSON state files does not migrate sessions or compression blocks.

## Changes

- Migrate the plugin entrypoint and runtime integration to the OpenCode V2 API ([#18](https://github.com/infituit/opencode-acp/pull/18)).
- Integrate tools, the `/acp` command, session hooks, events, and persistence with the V2 host.
- Convert V2 messages for ACP's existing compression and recovery pipeline.
- Retain model-driven three-tier compression, decompression, context status, and compressed-context search.

## Install from GitHub

With Git and Node.js/npm available, install the pinned release tag:

```bash
opencode plugin add github:infituit/opencode-acp#v2.0.0
```

Or add this entry to `opencode.json(c)`:

```json
{
    "$schema": "https://opencode.ai/config.json",
    "plugins": ["github:infituit/opencode-acp#v2.0.0"]
}
```

Run `/reload` after updating the configuration.
