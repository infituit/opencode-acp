## [Version: v2.0.0-alpha.12] - 2026-11-21

Full Changelog: [v2.0.0-alpha.11...v2.0.0-alpha.12](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.11...v2.0.0-alpha.12)

**Release scope**

- An ACP 2.0 Alpha media maintenance update fixing lost user attachments and tool media serialized as base64 text during V2 context transforms.

**Fixes**

- Preserve the host's projected user attachment text and native media objects, preventing images and files from being lost during context transforms while retaining attachment deduplication and ordering.
- Keep tool-returned files as structured media instead of serializing file objects and their base64 payloads as plain text. Preserve existing text trimming and tool-call pairing without restoring cleared tool output.
- Include supported inline images returned by tools in the existing image archive, retaining re-readable file pointers in compression summaries.

**Compatibility and upgrade prerequisites**

- Requires **OpenCode >=2.1.4 and <3**.
- No new configuration options or dependencies, and no changes to persisted formats, message refs, or compression block IDs. Upgrading from alpha.11 requires no data migration.
- Image archiving remains controlled by the existing `compress.images` settings. Remote images are not downloaded, and PDFs and SVGs are not archived.

**Known issues**

- Restoring media delivery does not eliminate its context usage or cost. Actual media handling still depends on the selected model and provider.
- This release does not include decompression-budget fixes or eliminate all long-history scanning and delays. Remaining issues in [#51](https://github.com/infituit/opencode-acp/issues/51) will continue to be addressed separately.
