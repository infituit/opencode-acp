## [Version: v2.0.0-alpha.14] - 2026-11-22

Full Changelog: [v2.0.0-alpha.13...v2.0.0-alpha.14](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.13...v2.0.0-alpha.14)

**Release scope**

- An ACP 2.0 Alpha context-accounting maintenance update fixing visible reasoning omitted from shared estimates.

**Fixes**

- Include reasoning retained in the current request in shared context estimates, avoiding undercounting when provider usage is unavailable. Reasoning removed at request time is no longer counted.
- Reuse shared accounting in decompression projections, removing the separate addition to avoid counting reasoning twice while preserving existing text/tool batching.

**Compatibility and upgrade prerequisites**

- Requires **OpenCode >=2.1.4 and <3**.
- No new configuration options or dependencies, and no changes to persisted formats, message refs, or compression block IDs. Upgrading from alpha.13 requires no data migration.
- Requests containing visible reasoning may trigger existing context notices or budget protection earlier. Reasoning-removal rules and historical provider usage handling are unchanged.

**Known issues**

- Context estimates still exclude actual native media costs and are not exact provider request budgets. This release does not resolve every issue tracked in [#51](https://github.com/infituit/opencode-acp/issues/51).
