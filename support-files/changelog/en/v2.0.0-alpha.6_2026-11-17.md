## [Version: v2.0.0-alpha.6] - 2026-11-17

Full Changelog: [v2.0.0-alpha.5...v2.0.0-alpha.6](https://github.com/infituit/opencode-acp/compare/v2.0.0-alpha.5...v2.0.0-alpha.6)

**Release scope**

- An ACP 2.0 Alpha performance maintenance update reducing repeated work in pre-request token usage estimation.

**Improvements**

- Reuse the tokenizer instance instead of initializing and freeing the WASM tokenizer for every count, preserving text normalization, special-token handling, and fallback behavior.
- Share the token count for the same message projection between batch cleanup and pre-pruning accounting to avoid duplicate scans. Post-pruning accounting is still recomputed.

**Compatibility and upgrade prerequisites**

- Requires **OpenCode >=2.1.4 and <3**.
- No changes to configuration, persisted state formats, message refs, or compression block IDs. Upgrading from alpha.5 requires no migration of these data.
- No text-content cache is introduced, and historical provider usage handling is unchanged.

**Known issues**

- This release targets repeated token-counting work. It does not resolve all long-history delays or image-compression issues tracked in [#51](https://github.com/infituit/opencode-acp/issues/51).
